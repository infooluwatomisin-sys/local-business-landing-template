# Local Business Landing Page Template

A free, responsive one page website template for local businesses: barbershops, salons, spas, clinics, cafes, studios and more.

Plain HTML, CSS and a few lines of JavaScript. No frameworks, no build step. Open `index.html` and it works.

## Features

- Mobile first, responsive layout with a hamburger menu
- Sections: hero, services with prices, gallery, reviews, booking call to action, contact with map
- Booking button that links to any booking tool (Booksy, Square, Fresha, Calendly)
- One place to change the brand colors (`:root` in `styles.css`)
- SEO and social preview meta tags
- Lightweight: loads fast on slow connections

## Quick start

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Replace the placeholder text, prices, reviews and contact details.
4. Add photos: set a `background-image` on `.hero__image` and each `.gallery__item`, or replace them with `<img>` tags.
5. Change `--brand` and `--accent` in `styles.css` to match the business.

## Deploy for free

- **Netlify:** drag the folder onto app.netlify.com/drop
- **GitHub Pages:** Settings, Pages, deploy from the `main` branch
- **Vercel:** import the repository and deploy

## File structure

```
index.html   page content
styles.css   design and responsive layout
script.js    mobile menu and footer year
```
